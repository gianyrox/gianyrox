Production system

DerbyFish

Demo / Site

Question

Build a competitive sport-fishing platform where catch submissions can be trusted at scale.

Role

Founding Product Engineer, full-time production work.

Method

Multi-repository system: Rust API, React Native and web clients, data pipelines, an automated highlight clipper, and a real-time catch-validation and anti-cheat pipeline (geolocation, timestamp, and duplicate-detection signals) as the core end-to-end feature, processing roughly 300 verified catches per derby.

Division of work

Human

Founding engineering role; not every repository or feature in the system was built solely by me, this is a multi-repository product with a small team.

AI

Used as an engineering tool across the codebase. Contribution is not broken out feature by feature.

Verification and limitations

Production system, live with paying users and real derbies.
